🩸 Emergency Blood Network

Real-Time Blood Donor and Blood Bank Availability Network

📌 About the Project

Emergency Blood Network is a web-based platform designed to help people find blood donors and blood bank availability during medical emergencies.

The system allows users to search for blood availability based on blood group and location, helping connect people in need with potential blood sources.

🎯 Problem Statement

During medical emergencies, finding compatible blood donors and nearby blood banks quickly can be difficult. This project aims to simplify the search process through a centralized platform.

✨ Key Features

- Search blood availability by blood group.
- Search using city or area.
- Display blood bank information.
- View available blood group counts.
- Simple and user-friendly interface.
- Backend integration using Node.js and Express.

🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- JSON

🚀 How to Run the Project

1. Clone the repository:
   
   "git clone https://github.com/nagamallahharshitha27-png/Emergency_Blood_Network.git"

2. Open the project folder:
   
   "cd Emergency_Blood_Network"

3. Install dependencies:
   
   "npm install"

4. Start the server:
   
   "node server.js"

5. Open your browser and visit:
   
   "http://localhost:5000"

🌍 Project Impact

The project aims to reduce the time required to locate blood sources and improve connections between blood donors, blood banks, and people in emergencies.
